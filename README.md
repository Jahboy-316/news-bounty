Entry for make.fun's bounty
[Sum up 19 November's world news in one image](https://make.fun/bounty/news-image-20261119).

`main.py` draws a newspaper-style front page for Thursday 19 November 2026
using only the Python standard library (own bitmap font and PNG encoder)
and writes it to `/output/entry.png`. It makes no network calls and is
deterministic, so both runs write the same bytes.

## Run it

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
